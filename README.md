# Sales Data Engineering & Revenue Intelligence Platform

A reproducible portfolio project that converts messy CRM-style opportunity records into curated datasets and a reporting mart using Python, Pandas, SQL, and an optional BigQuery warehouse.

> **Dataset notice:** All records are synthetic and generated specifically for this project. They do not represent a real business, customer, or employer. BigQuery and Looker Studio are optional cloud steps and require the user's own Google Cloud account.

## Capabilities

- Generate a 5,000-row synthetic CRM source plus controlled duplicates and data-quality issues.
- Clean text/date/numeric fields, deduplicate transaction IDs, validate required fields and positive deal amounts, and standardize missing dimensions.
- Produce an opportunity-level clean dataset, a month/region/channel/rep/stage sales mart, and a quality report.
- Load both datasets into explicitly typed, partitioned, clustered BigQuery tables.
- Run SQL data-quality and revenue reconciliation checks.
- Connect the aggregate mart to a Looker Studio revenue dashboard.
- Run automated unit tests and a full sample ETL run in GitHub Actions.

## Run locally

Requires Python 3.10+.

```bash
git clone https://github.com/shivamkr310/sales-data-engineering-revenue-intelligence.git
cd sales-data-engineering-revenue-intelligence
python -m venv .venv
```

Activate the environment:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Install core requirements, run the pipeline, and run tests:

```bash
pip install -r requirements.txt
python -m src.run_pipeline
python -m pytest -q
```

Outputs are written to `data/raw/` and `data/processed/`.

## Local interactive dashboard

A browser-based dashboard is included as a no-cloud preview. First run the ETL pipeline, then open `dashboard/index.html` in a browser and select `data/processed/sales_mart.csv`. It renders revenue and pipeline KPIs, monthly revenue, regional pipeline, sales-representative revenue, and stage/status tables. The CSV is read in the browser and is not sent to a server.

## BigQuery integration (optional)

### One-time setup

1. Create/select a Google Cloud project and enable the BigQuery API.
2. Install the optional client: `pip install -r requirements-cloud.txt`.
3. Authenticate locally: `gcloud auth application-default login`.
4. Set the project and optional dataset/location variables.

**Windows PowerShell**
```powershell
$env:GCP_PROJECT_ID="your-gcp-project-id"
$env:BQ_DATASET_ID="sales_analytics"
$env:BQ_LOCATION="US"
python -m src.load_bigquery
```

**macOS / Linux**
```bash
export GCP_PROJECT_ID="your-gcp-project-id"
export BQ_DATASET_ID="sales_analytics"
export BQ_LOCATION="US"
python -m src.load_bigquery
```

The loader creates the dataset if needed and loads explicit schemas. The detail table is partitioned by `created_date`; the sales mart is partitioned by `month_start`. Both are clustered by region, lead source, and sales representative. CSV loads replace the respective table contents, so review the target dataset before running against any existing production table.

## BigQuery SQL

Run the scripts in `sql/` in order after replacing `YOUR_PROJECT_ID`:

1. `01_create_dataset_tables.sql` — partitioned and clustered table definitions.
2. `02_data_quality_checks.sql` — uniqueness, null, amount/probability, and revenue reconciliation checks.
3. `03_build_sales_mart.sql` — rebuild the aggregate mart from detail data.

## Looker Studio dashboard

Follow [docs/dashboard_guide.md](docs/dashboard_guide.md) to connect `sales_analytics.sales_mart`, build scorecards and charts, add filters, and validate calculations. A published Looker Studio report is not included; it must be created and shared from the Google account that owns the data source.

Recommended KPIs include won revenue, opportunity value, opportunity count, and closed-deal win rate. The guide includes weighted calculations to avoid averaging already-aggregated group averages.

## Data dictionary

| Field | Description |
|---|---|
| transaction_id | Synthetic opportunity identifier |
| customer_id | Synthetic customer identifier |
| lead_id | Synthetic CRM lead identifier |
| sales_rep | Assigned sales representative |
| region | Sales territory |
| lead_source | Acquisition channel |
| product | Product/service category |
| deal_stage | Pipeline stage |
| created_date | Opportunity creation date |
| close_date | Close date when applicable |
| amount | Opportunity value in USD |
| probability | Estimated win probability, 0–1 |
| status | Open, Won, or Lost |
| revenue | Amount for Won opportunities, zero otherwise |
| created_month | Month label used in reporting |
| month_start | First day of the reporting month |

## Scope and limitations

This is a portfolio-scale demonstration, not a production sales platform. Cloud upload and dashboard publication require Google Cloud/Looker Studio access. No client results, cost savings, or query-performance improvements are claimed. Potential extensions include incremental loads, dbt models, scheduled orchestration, and query-cost benchmarking.
